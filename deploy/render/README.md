# Deploy Tiler to Render

A self-contained Render-deployable Tiler server with the `test_automation` preset auto-seeded on first boot.

## What this gives you

- A public URL (e.g. `https://tiler-demo.onrender.com`).
- The `test_automation` dashboard at `/dashboards/test_automation`.
- The full REST API at `/api/dashboards`, `/api/data_sources`, `/api/panels`.
- HMAC-signed ingestion at `/ingest/:slug` for pushing records.
- WebSocket live updates at `/ws`.
- The drag-resize editor at `/dashboards`.

## Deploy

1. Push this repo to GitHub (already done if you're reading this from `aguspe/tiler-ts`).
2. Go to <https://dashboard.render.com> → **New** → **Blueprint**.
3. Connect your GitHub account, pick this repo (`aguspe/tiler-ts`).
4. Render reads `render.yaml` at the root and shows a preview.
5. Click **Apply**. Render builds + deploys in ~3 minutes.
6. Open the assigned URL.

## What's in this directory

- `package.json` — npm package pinned to published `@aguspe/tiler-*` versions (no monorepo workspace deps).
- `start.ts` — boots `createServer({ presets: ["test_automation"] })`, listens on `process.env.PORT`, binds `0.0.0.0`.
- `tsconfig.json` — TypeScript config used by `tsx`.

## Env vars Render sets

- `PORT` — auto-injected by Render. `start.ts` reads it.
- `TILER_DB_PATH` — set to `./tiler.db` (ephemeral on free tier; mount a Disk for persistence).
- `TILER_WEBHOOK_SECRET` — auto-generated by Render's `generateValue: true`. Used for HMAC validation on `/ingest/:slug`. Surface it via the Render dashboard if you want to push records yourself.

## Free tier caveats

- **Cold-start spin-up**: ~30s after 15 min idle.
- **Ephemeral disk**: SQLite wiped on every cold-restart. The seed feature reseeds the preset on each boot, so the demo always has a working dashboard — but any dashboards you create in the editor disappear with the next restart.
- **Persistence**: uncomment the `disk:` block in `render.yaml` and switch to a paid plan.

## Push a record from your terminal

```bash
SERVER=https://your-tiler.onrender.com
SECRET=$(open the Render env tab and copy TILER_WEBHOOK_SECRET)

BODY='{"suite":"checkout","test_name":"manual","status":"fail","duration_ms":42}'
SIG=$(echo -n "$BODY" | openssl dgst -sha256 -hmac "$SECRET" -hex | sed 's/^.*= //')
curl -sS -X POST "$SERVER/ingest/test_runs" \
  -H "X-Tiler-Signature: sha256=$SIG" \
  -H "Content-Type: application/json" \
  -d "$BODY"
```

The dashboard's failure count and per-suite breakdown updates within ~1 second over WebSocket.

## Tweak the seeded dashboards

Edit `start.ts` and add a `dashboards: [...]` array next to `presets`:

```ts
import myDash from "./dashboards/my-team.tiler.config";

const config = defineConfig({
  // ...
  presets: ["test_automation"],
  dashboards: [myDash],
});
```

Each entry is an export from `definePlaywrightConfig({...})` (same shape `tiler-playwright` consumes locally). Render auto-redeploys on push.
